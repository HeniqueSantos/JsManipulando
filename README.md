# 🕹️ Hora do Desafio - Alura

Desafio básico de JavaScript proposto pela Alura, focado em praticar `alert()`, `prompt()`, `console.log()` e manipulação de DOM.

## 🚀 O que esse mini-projeto faz

- Mostra mensagens no console
- Exibe alertas com mensagens customizadas
- Usa `prompt()` pra capturar uma cidade e exibe um alerta com a resposta
- Realiza a soma de dois números digitados pelo usuário

## 📁 Tecnologias usadas

- HTML5
- CSS3
- JavaScript (básico)

## 👀 Como rodar

Só abrir o `index.html` em qualquer navegador. Simples assim.
